# QuickShop-Ecommerce

API desenvolvida em **Java com Spring Boot** para gerenciamento de carrinho de compras, idealizada como um microserviço básico dentro de um ecossistema de e-commerce.

---

## Tecnologias Utilizadas

- **Java 17**
- **Spring Boot**
- **Lombok**
- **MongoDB** (persistência)
- **Redis** (cache)
- **OpenFeign** (integração com API externa)
- **Docker**

---

## Como Executar o Projeto

### 🔹 Pré-requisitos

- Java 17+
- Maven
- Docker
- MongoDB
- Redis

### 🔹 Executando Docker Compose com containers MongoDB e Redis

No diretório "basketservice":
```bash
docker-compose up -d
```
